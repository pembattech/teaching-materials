00. Introduction to PHP

PHP (Hypertext Preprocessor) is a server-side scripting language used to build dynamic websites and web applications.

  • PHP code runs on the server, not in the browser.
  • PHP files are saved with the .php file extension.

Unlike HTML, which is used to structure web pages, PHP can perform calculations, process data, make decisions, and interact with databases to create dynamic content.

Popular Websites Built with PHP

  • Facebook (originally built with PHP)
  • WordPress
  • Wikipedia

Setting Up PHP

To run PHP on your computer, install one of the following packages:

  • XAMPP – Easy for beginners
  • WAMP – For Windows
  • MAMP – For Mac

These packages include:

  • Apache (Web Server)
  • PHP
  • MySQL (Database)

After installation:

  1. Start Apache.
  2. Place PHP files inside the htdocs folder.
  3. Open your browser and visit http://localhost/filename.php.

03. Variables

Variables are used to store data values.

<?php

$name = "John";
$age = 25;

echo $name;

?>

Rules for Variables

  • Variables must start with the $ symbol.
  • No need to declare a data type.
  • Variable names are case-sensitive.
  • Variable names cannot start with a number.

Variable Scope in PHP

Variable Scope defines where a variable can be accessed or used in a PHP program.

PHP has three main types of variable scope:

  • Local Scope
  • Global Scope
  • Static Scope

1️⃣ Local Scope

A variable declared inside a function can only be accessed within that function. 

        <?php

function test() {
    $x = 10;   // Local variable
    echo $x;
}

test();   // Works
// echo $x;  ❌ Error (cannot access outside)

?>

Local variables are created when the function starts and are destroyed when the function ends.

2️⃣ Global Scope

A variable declared outside a function is called a global variable. 

<?php

$y = 20;   // Global variable

function show() {
    // echo $y; ❌ Error
}

echo $y;  // ✅ Works

?>

By default, global variables cannot be accessed directly inside functions.

Using the global Keyword

To use a global variable inside a function, use the global keyword. 

        <?php
        
        $y = 20;
        
function show() {
    global $y;
    echo $y;
}

show();   // Outputs: 20

?>

3️⃣ Static Scope

Normally, local variables are deleted when a function finishes execution.

Using the static keyword allows a variable to retain its value between function calls. 

        <?php

function counter() {
    static $count = 0;

    $count++;
    
    echo $count . "<br>";
    }
    
    counter(); // 1
    counter(); // 2
    counter(); // 3
    
    ?>

Without the static keyword, the variable would be recreated each time the function runs, so it would always output 1.

04. Data Types in PHP

Data Types define the type of information a variable can store.

  • String → "Hello"
  • Integer → 10
  • Float → 10.5
  • Boolean → true / false
  • Null → NULL
  • Array → array()

Examples of Data Types

<?php

$name = "Hello";      // String
$age = 10;            // Integer
$price = 10.5;       // Float
$isActive = true;        // Boolean
$data = NULL;            // Null
$colors = array("Red", "Blue"); // Array

?>

Type Casting in PHP

Type Casting is the process of converting a variable from one data type to another.

Syntax

$newVar = (type) $variable;

Common casting types:

  • (int) → Integer
  • (float) → Float
  • (string) → String
  • (bool) → Boolean
  • (array) → Array
  • (object) → Object

Examples

<?php

$var = "123.45";

$intVar   = (int)$var;          // 123
$floatVar = (float)$var;        // 123.45
$strVar   = (string)100;   // "100"
$boolVar  = (bool)0;     // false
$arrayVar = (array)"Hi";  // ["Hi"]

$objVar = (object)[
    "a" => 1
];                             // Object with property a = 1

?>

Important Notes

  • Boolean Casting: 0, "", and NULL become false. Everything else becomes true.
  • Integer Casting: Decimal values are truncated (the fractional part is removed). 
<?php

echo (int)10.99;   // Output: 10

?>

8. Conditional (Ternary) Operator

The ternary operator is a shorthand form of an if...else statement. 

<?php

echo ($age >= 18)
    ? "Adult"
    : "Minor";

// Output: Adult

?>

Localhost

localhost is a hostname that points to your own computer.

It uses the loopback network interface, meaning any request sent to localhost stays on your device instead of going through the internet.

How to Access Localhost

Using a Web Browser:

  1. Open any web browser (Chrome, Firefox, Edge, etc.).
  2. Type http://localhost or http://127.0.0.1 in the address bar.
  3. Press Enter to access your local web server.
http://localhost

or

http://127.0.0.1

Benefits of Localhost

1. Safe Testing Environment

Test websites, web applications, and scripts without exposing them to the internet.

2. Faster Development

Access your server and applications locally without network delays.

3. No Internet Required

Since everything runs on your own computer, an internet connection is not required.

4. Debugging & Troubleshooting

Errors can be identified and fixed before deploying the application to a live server.

5. Better Security

Localhost is isolated from external networks, reducing security risks during development.

6. Easy Experimentation

Developers can test different configurations, databases, and server settings without affecting the live system.

Example

If a file named index.php is stored inside the htdocs folder of XAMPP, it can be accessed using: 

http://localhost/index.php

Localhost is commonly used with web development tools such as XAMPP, WAMP, and MAMP for testing PHP applications.

Different Ways to Print Data in PHP

PHP provides several ways to display output and inspect variables.

1. Basic Output with echo

The echo statement is used to display text, variables, and HTML content. 

<?php

$name = "Alice";

echo "Hello, $name!";

?>

Output:

Hello, Alice!

2. Debugging Variable Structure with print_r()

The print_r() function displays human-readable information about arrays and objects. 

<?php

$fruits = array(
    "apple",
    "banana",
    "orange"
);

print_r($fruits);

?>

Output:

Array
(
    [0] => apple
    [1] => banana
    [2] => orange
)

print_r() is useful when working with arrays and objects during development.

3. In-depth Debugging with var_dump()

The var_dump() function displays detailed information about a variable, including its data type and value. 

<?php

$person = array(
    "name" => "Bob",
    "age" => 30,
    "hobbies" => array(
        "reading",
        "hiking"
    )
);

var_dump($person);

?>

Output:

array(3) {
  ["name"]=>
  string(3) "Bob"
  ["age"]=>
  int(30)
  ["hobbies"]=>
  array(2) {
    [0]=>
    string(7) "reading"
    [1]=>
    string(6) "hiking"
  }
}

var_dump() is especially useful for debugging because it shows:

  • Data type of the variable
  • Length of strings
  • Array size
  • Actual stored values

Summary

Method Purpose
echo Display text, variables, and HTML content
print_r() Display arrays and objects in readable form
var_dump() Display detailed type and value information
