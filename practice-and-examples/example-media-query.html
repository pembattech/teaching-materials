Key Media Query Features

Width-based

@media (max-width: 768px) - Targets screens up to 768px wide.

Orientation

@media (orientation: landscape) - Targets landscape or portrait mode.

Pixel Ratio

@media (-webkit-min-device-pixel-ratio: 2) - Targets high-resolution displays.
