03. Data Types

Data types define the type of value a variable can store.

  • Primitive Types:: These store single values and they are immutable.

    Type Description Example
    String Text enclosed in quotes let name = "Pemba";
    Number Numeric values let age = 30;
    Boolean true or false let isStudent = true;
    Null Inentional empty value let empty=null;
    Undefined Variable declared but not assigned let x;
    BigInt For very large numbers. let bigNum = 12345678901234567890n;

  • Non-Primitive (Reference) Data Types: These store collections or complex data. They are mutable.

    • Array: Collection of values

      Example: let fruits = ["Apple", "Banana", "Mango"];

      Accessing Array Elements

      Array elements are accesed using index

      Example: 
      let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[0]); // Output: Apple
console.log(fruits[1]); // Output: Banana

      Adding Elements to an Array

      • push(): At the End

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.push("Grapes");

console.log(fruits); // Output: ["Apple", "Banana", "Mango", "Grapes"]

      • unshift(): At the Beginning

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.unshift("Strawberry");

console.log(fruits); // Output: ["Strawberry", "Apple", "Banana", "Mango"]

      Remove Elements from an Array

      • pop(): From the End

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.pop(); // Removes "Grapes"

console.log(fruits); // Output: ["Apple", "Banana", "Mango"]

      • shift(): From the Beginning

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.shift(); // Removes "Apple"

console.log(fruits); // Output: ["Banana", "Mango"]

      Updating Array Elements

      Changing the value at a specific index

      Example: 
      let fruits = ["Apple", "Banana", "Mango"];
fruits[1] = "Orange"; // Replace "Banana" with "Orange"

console.log(fruits); // Output: ["Apple", "Orange", "Mango"]

    • Object: Collection of Key-value pairs

      Example: let person = { name: "Pemba", age: 30 };

      Add Values

      let person = {
    name: "Pemba"
};

person.age = 30;

      Update Values

      let person = {
    name: "Pemba",
    age: 25
};

person.age = 30;

      Delete Values

      let person = {
    name: "Pemba",
    age: 30
};

delete person.age;

05. Functions

A function is a reusable block of code that performs a specific task. 

function greet(name){
    return "Hello " + name;
}
greet("Pemba");

Parameters and Arguments

  • A parameter is a variable inside a function that receives a value when the function is called.
  • An argument is the actual value passed when the function is called.

Return Statement

The return statement sends a value back from the function. 

function add(a, b){
  return a + b;
}

let result = add(5, 3);

console.log(result);

Types of Function in JavaScript

  1. Named Functions
  2. Anonymous Functions
  3. Arrow Functions

1. Named Functions

A named function has its own function name. 

function add(a, b){
  console.log(a + b);
}

2. Anonymous Functions

An anonymous function does not have a function name. It is usually stored inside a variable. 

let add = function(a, b){
  console.log(a + b);
}

3. Arrow Functions

Arrow functions provide a shorter syntax for writing functions. 

let add = (a, b) => {
  console.log(a + b);
}

06. Control Flow

Control flow means the order in which JavaScript executes your code.

By default, JavaScript runs code line by line from top to bottom.

But sometimes we want to:

  • ✅ Make decisions
  • 🔁 Repeat code
  • ⏭ Skip certain parts

Types of Control Flow in JavaScript

1. Sequential Control Flow

In sequential flow, code runs line by line in order. 

let a = 5;
let b = 10;

console.log(a + b);

✔ JavaScript executes the code from top to bottom.

2. Conditional Control Flow (Decision Making)

Conditional statements allow JavaScript to make decisions based on conditions.

  • Basic if Statement

    The if statement is used to execute code only if a condition is true.

    Syntax

    if (condition) {
    // code runs if condition is true
}

    Example

    let age = 20;
if (age >= 18) {
    console.log("You are an adult");
}

  • if...else Statement

    Used when you want two possible outcomes.

    Syntax

    if (condition) {
// runs if true
} else {
// runs if false
}

    Example

    let age = 16;
        
if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

  • if...else if...else Statement

    Used when checking multiple conditions.

    Syntax

    if (condition1) {

    // block 1

} else if (condition2) {

    // block 2

} else {

    // default block

}

    Example

    let score = 75;
        
if (score >= 90) {
    console.log("Grade A");
} else if (score >= 70) {
    console.log("Grade B");
} else if (score >= 50) {
    console.log("Grade C");
} else {
    console.log("Fail");
}

  • Switch Statement in JavaScript

    The switch statement is another way to make decisions in JavaScript.

    It is useful when you have multiple conditions based on a single value.

    Syntax

    switch (expression) {

case value1:
// code
break;

case value2:
// code
break;

default:
// default code

}

    Example: Basic Switch Statement

    let day = 3;
let dayName;

switch (day) {

    case 1:
    dayName = "Monday";
    break;

    case 2:
    dayName = "Tuesday";
    break;

    case 3:
    dayName = "Wednesday";
    break;

    case 4:
    dayName = "Thursday";
    break;

    default:
    dayName = "Unknown day";

}

console.log(dayName);
    Output:
Wednesday

3. Looping Control Flow (Iteration)

Loops are used to repeat code multiple times.

Types of Loops in JavaScript

  • for loop – Repeats code a specific number of times.
  • while loop – Repeats code while a condition is true.
  • do...while loop – Runs the code once, then repeats while a condition is true.
  • for...of loop – Iterates through values in an iterable object like an array.
  • for...in loop – Iterates through the properties of an object.

  • For Loop

    The for loop is used when you know how many times you want to repeat a block of code.

    Syntax

    for (initialization; condition; increment/decrement) {
    // code to run
}

    Example

    for (let i = 1; i <= 5; i++) {
    console.log("Number: " + i);
}

    Output

    Number: 1
Number: 2
Number: 3
Number: 4
Number: 5

  • While Loop

    The while loop executes a block of code repeatedly as long as the specified condition is true.

    Syntax

    while (condition) {
    // code to run
}

    Example

    let i = 1;

while (i <= 5) {
    console.log("Count: " + i);
    i++;
}

    Output

    Count: 1
Count: 2
Count: 3
Count: 4
Count: 5

  • Do...While Loop

    The do...while loop executes the code block once before checking the condition. It will always run at least one time.

    Syntax

    do {
    // code to run
} while (condition);

    Example

    let i = 1;

do {
    console.log("Step: " + i);
    i++;
} while (i <= 5);

    Output

    Step: 1
Step: 2
Step: 3
Step: 4
Step: 5

    Even if the condition is false, the do...while loop executes the code once before checking the condition.

  • For...of Loop

    The for...of loop is used to iterate through the values of an array or other iterable objects.

    Example

    let fruits = ["Apple", "Banana", "Mango"];

for (let fruit of fruits) {
    console.log(fruit);
}

    Output

    Apple
Banana
Mango

  • For...in Loop

    The for...in loop is used to iterate through the keys (properties) of an object.

    Example

    let person = {
    name: "John",
    age: 30,
    city: "NY"
};

for (let key in person) {
    console.log(key + ": " + person[key]);
}

    Output

    name: John
age: 30
city: NY

07. JavaScript in HTML

JavaScript can be added inside an HTML file using the <script> tag. It makes webpages interactive and dynamic.

There are 3 common ways to add JavaScript to HTML:

1. Inline JavaScript

Inline JavaScript is written directly inside an HTML element using event attributes. 

<button onclick="alert('Hello World')">Click Me</button>

Use case: Small actions like button clicks.

Not recommended for large projects because it mixes HTML and JavaScript.

2. Internal JavaScript

Internal JavaScript is written inside the <script> tag within the same HTML file. 

<!DOCTYPE html>
<html>
<head>
    <title>Internal JS</title>
</head>
<body>

<button onclick="showMessage()">Click</button>

<script>
function showMessage(){
    alert("Hello World");
}
</script>

</body>
</html>

Use case: Small projects or quick testing.

3. External JavaScript (Best Practice)

External JavaScript is written in a separate .js file and linked to the HTML file.

HTML file:

<script src="script.js"></script>

script.js file:

function showMessage(){
    alert("Hello World");
}

Advantages:

  • Cleaner HTML
  • Reusable code
  • Easier maintenance
  • Faster loading with caching

08. DOM (Document Object Model) in JavaScript

The DOM is a representation of the HTML document as a tree of objects.

Each element, attribute, and text node in HTML becomes a node in the DOM. JavaScript can read, update, add, or remove nodes dynamically.

1️⃣ Selecting DOM Elements

🔹 1. getElementById

<p id="demo">Hello!</p>

<script>
let p = document.getElementById("demo");
console.log(p);
</script>

Output in console:

<p id="demo">Hello!</p>

🔹 2. getElementsByClassName / getElementsByTagName

<p class="text">First</p>
<p class="text">Second</p>

<script>
let texts = document.getElementsByClassName("text");
console.log(texts[0].innerText); // Access first element
</script>

Output:

First

🔹 3. querySelector & querySelectorAll (Modern Way)

<p class="text">Hello</p>

<script>
let para = document.querySelector(".text"); // selects first element
console.log(para.innerText);

let allParas = document.querySelectorAll("p"); // selects all <p> elements
console.log(allParas.length);
</script>

Output:

Hello
2

querySelector uses CSS selectors, so it is very flexible.

Changing Content & Attributes

🔹 1. Change Text

<p id="demo">Old Text</p>

<script>
let p = document.getElementById("demo");
p.innerText = "New Text!";
</script>

Result on page:

New Text!

🔹 2. Change HTML

<div id="box">Hello</div>

<script>
let box = document.getElementById("box");
box.innerHTML = "<b>Bold Text!</b>";
</script>

Result on page:

Bold Text!

🔹 3. Change Attributes

<img id="logo" src="old.png" alt="Logo">

<script>
let logo = document.getElementById("logo");
logo.src = "new.png"; // update image source
logo.alt = "New Logo";
</script>

3️⃣ Adding & Removing Elements

🔹 1. Create Element

let newPara = document.createElement("p");
newPara.innerText = "I am a new paragraph!";
document.body.appendChild(newPara);

Result: A new paragraph is added at the end of the page.

🔹 2. Remove Element

let oldPara = document.getElementById("demo");
oldPara.remove();

Result: The element with id demo is removed from the page.

4️⃣ Changing Styles Dynamically

let box = document.getElementById("box");
box.style.backgroundColor = "lightblue";
box.style.fontSize = "20px";
box.style.padding = "10px";

Result: The element’s style is updated in real-time.

09. DOM Events in JavaScript

DOM events are actions that happen in the browser, such as:

  • Clicking a button
  • Typing in an input field
  • Hovering over an element
  • Submitting a form

JavaScript can listen to these events and run code when they occur.

1️⃣ How to Add Events

🔹 1. Using HTML onclick (Old Way)

<button onclick="alert('Button clicked!')">Click Me</button>

Output: Clicking the button shows an alert.

✅ Works but not recommended for large projects because it mixes HTML and JavaScript.

🔹 2. Using JavaScript onclick

<button id="btn">Click Me</button>

<script>
let button = document.getElementById("btn");

button.onclick = function() {
    alert("Button clicked using JS!");
};
</script>

Output: Clicking the button shows an alert.

❌ Limitation: If you assign another onclick, it overwrites the first one.

🔹 3. Using addEventListener (Recommended)

<button id="btn">Click Me</button>

<script>
let button = document.getElementById("btn");

button.addEventListener("click", () => {
    alert("Button clicked with addEventListener!");
});
</script>

Output: Works the same, but you can add multiple events without overwriting.

2️⃣ Common DOM Events

click      → Fired when an element is clicked
dblclick   → Fired on double click
mouseover  → When mouse moves over an element
mouseout   → When mouse leaves an element
keydown    → When a key is pressed
keyup      → When a key is released
input      → When input value changes
change     → When input loses focus after value change
submit     → When form is submitted
focus      → When an element gains focus
blur       → When an element loses focus

3️⃣ Examples

🔹 Click Event

<button id="btn">Click Me</button>

<script>
document.getElementById("btn").addEventListener("click", () => {
    console.log("Button was clicked!");
});
</script>

Output in console:

Button was clicked!

🔹 Mouseover Event

<p id="hoverText">Hover over me!</p>

<script>
let text = document.getElementById("hoverText");

text.addEventListener("mouseover", () => {
    text.style.color = "red";
});

text.addEventListener("mouseout", () => {
    text.style.color = "black";
});
</script>

Result: Text turns red when hovered, black when mouse leaves.

🔹 Input Event

<input type="text" id="nameInput" placeholder="Type your name">
<p id="greeting"></p>

<script>
let input = document.getElementById("nameInput");
let greeting = document.getElementById("greeting");

input.addEventListener("input", () => {
    greeting.innerText = "Hello, " + input.value + "!";
});
</script>

Result: As you type, the paragraph updates in real-time.

🔹 Form Submit Event

<form id="myForm">
  <input type="text" placeholder="Enter something" id="myInput">
  <button type="submit">Submit</button>
</form>

<script>
let form = document.getElementById("myForm");

form.addEventListener("submit", (e) => {
    e.preventDefault(); // Prevent page reload
    alert("Form Submitted!");
});
</script>

Result: Clicking submit triggers alert without reloading the page.

4️⃣ Removing Events

function sayHi() {
    console.log("Hi!");
}

button.addEventListener("click", sayHi);

// Later remove it
button.removeEventListener("click", sayHi);

5️⃣ Event Object

When an event occurs, JavaScript passes an event object with information about the event. 

document.getElementById("btn").addEventListener("click", (event) => {
    console.log(event.type);   // "click"
    console.log(event.target); // The element clicked
});
