03. Data Types

Data types define the type of value a variable can store.

  • Primitive Types:: These store single values and they are immutable.

    Type Description Example
    String Text enclosed in quotes let name = "Pemba";
    Number Numeric values let age = 30;
    Boolean true or false let isStudent = true;
    Null Inentional empty value let empty=null;
    Undefined Variable declared but not assigned let x;
    BigInt For very large numbers. let bigNum = 12345678901234567890n;

  • Non-Primitive (Reference) Data Types: These store collections or complex data. They are mutable.

    • Array: Collection of values

      Example: let fruits = ["Apple", "Banana", "Mango"];

      Accessing Array Elements

      Array elements are accesed using index

      Example: 
      let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[0]); // Output: Apple
console.log(fruits[1]); // Output: Banana

      Adding Elements to an Array

      • push(): At the End

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.push("Grapes");

console.log(fruits); // Output: ["Apple", "Banana", "Mango", "Grapes"]

      • unshift(): At the Beginning

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.unshift("Strawberry");

console.log(fruits); // Output: ["Strawberry", "Apple", "Banana", "Mango"]

      Remove Elements from an Array

      • pop(): From the End

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.pop(); // Removes "Grapes"

console.log(fruits); // Output: ["Apple", "Banana", "Mango"]

      • shift(): From the Beginning

        Example: 
        let fruits = ["Apple", "Banana", "Mango"];
fruits.shift(); // Removes "Apple"

console.log(fruits); // Output: ["Banana", "Mango"]

      Updating Array Elements

      Changing the value at a specific index

      Example: 
      let fruits = ["Apple", "Banana", "Mango"];
fruits[1] = "Orange"; // Replace "Banana" with "Orange"

console.log(fruits); // Output: ["Apple", "Orange", "Mango"]

    • Object: Collection of Key-value pairs

      Example: let person = { name: "Pemba", age: 30 };

      Add Values

      let person = {
    name: "Pemba"
};

person.age = 30;

      Update Values

      let person = {
    name: "Pemba",
    age: 25
};

person.age = 30;

      Delete Values

      let person = {
    name: "Pemba",
    age: 30
};

delete person.age;

05. Functions

A function is a reusable block of code that performs a specific task. 

function greet(name){
    return "Hello " + name;
}
greet("Pemba");

Parameters and Arguments

  • A parameter is a variable inside a function that receives a value when the function is called.
  • An argument is the actual value passed when the function is called.

Return Statement

The return statement sends a value back from the function. 

function add(a, b){
  return a + b;
}

let result = add(5, 3);

console.log(result);

Types of Function in JavaScript

  1. Named Functions
  2. Anonymous Functions
  3. Arrow Functions

1. Named Functions

A named function has its own function name. 

function add(a, b){
  console.log(a + b);
}

2. Anonymous Functions

An anonymous function does not have a function name. It is usually stored inside a variable. 

let add = function(a, b){
  console.log(a + b);
}

3. Arrow Functions

Arrow functions provide a shorter syntax for writing functions. 

let add = (a, b) => {
  console.log(a + b);
}

06. Control Flow

Control flow means the order in which JavaScript executes your code.

By default, JavaScript runs code line by line from top to bottom.

But sometimes we want to:

  • ✅ Make decisions
  • 🔁 Repeat code
  • ⏭ Skip certain parts

Types of Control Flow in JavaScript

1. Sequential Control Flow

In sequential flow, code runs line by line in order. 

let a = 5;
let b = 10;

console.log(a + b);

✔ JavaScript executes the code from top to bottom.

2. Conditional Control Flow (Decision Making)

Conditional statements allow JavaScript to make decisions based on conditions.

  • Basic if Statement

    The if statement is used to execute code only if a condition is true.

    Syntax

    if (condition) {
    // code runs if condition is true
}

    Example

    let age = 20;
if (age >= 18) {
    console.log("You are an adult");
}

  • if...else Statement

    Used when you want two possible outcomes.

    Syntax

    if (condition) {
// runs if true
} else {
// runs if false
}

    Example

    let age = 16;
        
if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

  • if...else if...else Statement

    Used when checking multiple conditions.

    Syntax

    if (condition1) {

    // block 1

} else if (condition2) {

    // block 2

} else {

    // default block

}

    Example

    let score = 75;
        
if (score >= 90) {
    console.log("Grade A");
} else if (score >= 70) {
    console.log("Grade B");
} else if (score >= 50) {
    console.log("Grade C");
} else {
    console.log("Fail");
}

  • Switch Statement in JavaScript

    The switch statement is another way to make decisions in JavaScript.

    It is useful when you have multiple conditions based on a single value.

    Syntax

    switch (expression) {

case value1:
// code
break;

case value2:
// code
break;

default:
// default code

}

    Example: Basic Switch Statement

    let day = 3;
let dayName;

switch (day) {

    case 1:
    dayName = "Monday";
    break;

    case 2:
    dayName = "Tuesday";
    break;

    case 3:
    dayName = "Wednesday";
    break;

    case 4:
    dayName = "Thursday";
    break;

    default:
    dayName = "Unknown day";

}

console.log(dayName);
    Output:
Wednesday
